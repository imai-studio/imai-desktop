# IMAI desktop

Download the IMAI desktop app for macOS from the
[latest release](https://github.com/imai-studio/imai-desktop/releases/latest).

- Apple silicon: `IMAI-<version>-arm64.dmg`
- Intel: `IMAI-<version>-x64.dmg`

Builds are signed with a Developer ID certificate and notarized by Apple. The
app updates itself in place once installed.

This repository only hosts release downloads. Releases are published
automatically from the IMAI source repository.
